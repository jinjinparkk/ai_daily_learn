오늘의 기초 · Fundamentals

인컨텍스트 러닝 In-Context Learning
이게 뭐야? · What is it
ENIn-context learning is a model's ability to perform a new task simply by reading examples inside the prompt, without updating its weights.
KO인컨텍스트 러닝은 모델이 가중치를 바꾸지 않고, 프롬프트 안에 담긴 예시를 읽는 것만으로 새로운 작업을 수행하는 능력입니다.
ENYou give the model a few demonstrations of input and output, and it infers the pattern to handle a fresh input.
KO모델에게 입력과 출력의 예시 몇 개를 주면, 모델은 그 패턴을 추론하여 새로운 입력을 처리합니다.
ENThis is different from traditional training, where the model must be retrained on new data to learn a task.
KO이것은 새로운 작업을 배우기 위해 모델을 새 데이터로 재학습해야 하는 전통적인 학습과는 다릅니다.
작동 원리 · How it works
ENA large language model is first pretrained on massive text to predict the next token in a sequence.
KO대형 언어 모델은 먼저 방대한 텍스트로 사전학습되어 문장 속 다음 토큰을 예측하도록 훈련됩니다.
ENDuring this pretraining, it sees countless patterns where a context predicts what comes next.
KO이 사전학습 과정에서 모델은 어떤 맥락이 다음에 올 내용을 예측하는 수많은 패턴을 접합니다.
ENAt inference time, the examples you place in the prompt act as a temporary 'context' that steers its predictions.
KO추론 시점에 프롬프트에 넣는 예시들은 모델의 예측을 이끄는 임시 '맥락' 역할을 합니다.
ENThe model attends to these examples using its attention mechanism and mimics the demonstrated input-output relationship.
KO모델은 어텐션 메커니즘을 통해 이 예시들에 주목하고, 보여준 입력-출력 관계를 모방합니다.
ENZero-shot means no examples, few-shot means a handful of examples, and both rely on the same underlying skill.
KO제로샷은 예시가 없는 경우, 퓨샷은 예시가 몇 개 있는 경우를 뜻하며, 둘 다 같은 근본 능력에 기반합니다.
ENCrucially, the model's parameters stay frozen; the 'learning' happens only within the current conversation.
KO핵심은 모델의 파라미터가 고정된 채로 유지된다는 점이며, '학습'은 오직 현재 대화 안에서만 일어납니다.
🧩 비유로 이해 · Analogy
ENIt is like handing a skilled translator a short glossary right before they speak; they use it on the spot without going back to school.
KO숙련된 통역사에게 말하기 직전에 짧은 용어집을 건네는 것과 같습니다. 통역사는 다시 학교로 돌아가지 않고 그 자리에서 바로 활용합니다.
기본 용어 · Key terms
Prompt (프롬프트)모델에게 주는 입력 텍스트로, 지시문과 예시를 포함할 수 있습니다.
Few-shot (퓨샷)프롬프트 안에 소수의 예시를 제공하여 작업을 유도하는 방식.
Zero-shot (제로샷)예시 없이 지시만으로 작업을 수행하게 하는 방식.
Attention (어텐션)입력의 어느 부분에 집중할지 결정하는 트랜스포머의 핵심 메커니즘.
Frozen weights (고정 가중치)추론 중 변경되지 않는, 사전학습으로 정해진 모델 파라미터.

오늘의 핵심 개념 · Key Concept

비전-언어 모델의 3D 공간 인식 3D Spatial Awareness in Vision-Language Models
ENMost vision-language models are trained on flat 2D images, so they struggle with true depth and spatial relationships.
KO대부분의 비전-언어 모델은 평면적인 2D 이미지로 학습되어, 진짜 깊이와 공간 관계를 다루는 데 어려움을 겪습니다.
EN3D spatial awareness means a model can reason about where objects are in space, not just what they look like.
KO3D 공간 인식이란 모델이 사물이 어떻게 생겼는지뿐 아니라 공간 어디에 있는지도 추론할 수 있음을 뜻합니다.
ENSome methods add explicit 3D structure, like reconstructed geometry, while others learn implicit geometric priors from ordinary videos.
KO어떤 방법은 복원된 기하 구조 같은 명시적 3D 정보를 추가하고, 다른 방법은 평범한 영상에서 암묵적 기하 사전지식을 학습합니다.
ENCombining both implicit and explicit cues lets a model understand fine-grained space using only RGB video as input.
KO암묵적 단서와 명시적 단서를 결합하면, 모델은 RGB 영상만 입력으로 받고도 세밀한 공간을 이해할 수 있습니다.
ENThis matters for tasks like 3D detection, visual grounding, and spatial reasoning where 2D features alone fall short.
KO이는 2D 특징만으로는 부족한 3D 탐지, 시각적 그라운딩, 공간 추론 같은 작업에서 중요합니다.
왜 지금? · Why now
ENAs AI moves into robotics, AR glasses, and physical simulation, understanding real 3D space becomes essential rather than optional.
KOAI가 로보틱스, AR 글래스, 물리 시뮬레이션으로 확장되면서 실제 3D 공간을 이해하는 능력은 선택이 아닌 필수가 되고 있습니다.

autoregressive
