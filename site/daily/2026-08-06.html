오늘의 기초 · Fundamentals

양자화 Quantization
이게 뭐야? · What is it
ENQuantization is the process of representing a model's numbers with fewer bits, for example turning 32-bit or 16-bit values into 8-bit or 4-bit ones.
KO양자화는 모델의 숫자를 더 적은 비트로 표현하는 과정으로, 예를 들어 32비트나 16비트 값을 8비트나 4비트로 바꾸는 것입니다.
ENThe goal is to shrink the model's size and speed up computation while keeping its accuracy as close to the original as possible.
KO목표는 정확도를 원본에 최대한 가깝게 유지하면서 모델의 크기를 줄이고 계산 속도를 높이는 것입니다.
ENIt matters most for deployment, when you want a model to run on a laptop, a phone, or a single GPU instead of a large server.
KO이는 특히 배포 단계에서 중요한데, 큰 서버 대신 노트북, 휴대폰, 또는 GPU 한 대에서 모델을 돌리고 싶을 때 그렇습니다.
작동 원리 · How it works
ENA neural network stores its knowledge as weights, which are just large tables of decimal numbers.
KO신경망은 지식을 가중치로 저장하는데, 이는 그저 소수(小數)로 이루어진 커다란 표에 불과합니다.
ENFull precision uses many bits per number, which gives fine detail but takes a lot of memory and computation.
KO완전 정밀도는 숫자 하나당 많은 비트를 사용해 세밀한 표현이 가능하지만, 많은 메모리와 계산을 필요로 합니다.
ENQuantization maps a wide range of real values onto a small set of discrete levels, using a scale factor to convert back and forth.
KO양자화는 넓은 범위의 실수 값을 소수의 이산적인 단계로 대응시키며, 스케일 팩터를 이용해 값을 양방향으로 변환합니다.
ENPost-training quantization compresses a finished model directly, which is fast but can lose some accuracy.
KO훈련 후 양자화는 완성된 모델을 직접 압축하는 방식으로, 빠르지만 정확도를 다소 잃을 수 있습니다.
ENQuantization-aware training simulates the rounding during training, so the model learns to stay accurate under low precision.
KO양자화 인식 훈련은 훈련 중에 반올림을 시뮬레이션하여, 모델이 낮은 정밀도에서도 정확도를 유지하도록 학습하게 합니다.
ENThe main trade-off is compression versus quality: fewer bits save more memory but risk larger errors in the model's outputs.
KO핵심적인 절충은 압축과 품질 사이에 있습니다. 비트가 적을수록 더 많은 메모리를 아끼지만 모델 출력에서 더 큰 오차가 생길 위험이 있습니다.
🧩 비유로 이해 · Analogy
ENThink of quantization like saving a photo as a smaller file: you reduce the number of colors, so the file becomes much lighter and still looks almost the same, but zoom in too far and you notice the loss of detail.
KO양자화는 사진을 더 작은 파일로 저장하는 것과 비슷합니다. 색상 수를 줄이면 파일이 훨씬 가벼워지고 여전히 거의 똑같아 보이지만, 너무 확대하면 세부의 손실이 눈에 띕니다.
기본 용어 · Key terms
Precision (정밀도)숫자를 표현하는 데 쓰는 비트 수. 예: FP32, FP16, INT8, INT4.
Scale factor (스케일 팩터)실수 값과 이산적인 정수 단계 사이를 변환할 때 곱해 주는 값.
Post-training quantization (훈련 후 양자화)이미 훈련된 모델을 재훈련 없이 낮은 정밀도로 변환하는 방법.
Quantization-aware training (양자화 인식 훈련)훈련 과정에서 양자화 오차를 반영해 낮은 정밀도에서도 정확도를 지키도록 학습하는 방법.

오늘의 핵심 개념 · Key Concept

테스트 타임 스케일링 Test-Time Scaling
ENTest-time scaling means giving a model more computation at inference time so it can solve harder problems.
KO테스트 타임 스케일링이란 모델이 더 어려운 문제를 풀 수 있도록 추론 시점에 더 많은 계산을 투입하는 것을 뜻합니다.
ENInstead of only making the model bigger, you let it think longer, sample many answers, or search over partial solutions.
KO모델을 더 크게 만드는 대신, 더 오래 생각하게 하거나 여러 답을 표본으로 뽑거나 부분 해답을 탐색하게 하는 것입니다.
ENOne common form extends a single line of reasoning; another samples many complete answers and votes on them.
KO흔한 한 가지 방식은 하나의 추론 흐름을 길게 늘리는 것이고, 다른 방식은 여러 개의 완결된 답을 뽑아 투표로 결정하는 것입니다.
ENToday's survey paper warns that these methods have different statistical structures, so treating them as one single 'budget' makes results hard to compare.
KO오늘의 서베이 논문은 이 방법들이 서로 다른 통계적 구조를 가지므로, 이를 하나의 '예산'으로 뭉뚱그리면 결과를 비교하기 어렵다고 경고합니다.
ENThe lesson is to always report the exact inference protocol, not just an accuracy number.
KO교훈은 정확도 수치만이 아니라 정확히 어떤 추론 절차를 썼는지를 항상 함께 보고해야 한다는 것입니다.
왜 지금? · Why now
ENAs models get compressed to run on small devices, deciding how to spend limited inference compute wisely becomes just as important as the model's raw size.
KO모델이 작은 기기에서 돌아가도록 압축됨에 따라, 제한된 추론 계산을 어떻게 현명하게 쓸지 정하는 일이 모델의 순수한 크기만큼이나 중요해집니다.

핵심 영어 표현 · Vocabulary

quantization
양자화 (숫자를 더 적은 비트로 표현해 모델을 압축하는 기법)
“Quantization lets a large model run on a laptop with far less memory.”
양자화 덕분에 큰 모델을 훨씬 적은 메모리로 노트북에서 돌릴 수 있습니다.
inference
추론 (훈련된 모델이 실제로 예측이나 출력을 생성하는 단계)
“Running the model at inference time on a phone requires efficient computation.”
휴대폰에서 추론 시점에 모델을 돌리려면 효율적인 계산이 필요합니다.
latency
지연 시간 (입력을 넣고 결과가 나올 때까지 걸리는 시간)
“The voice system uses a low-latency architecture for natural conversation.”
그 음성 시스템은 자연스러운 대화를 위해 저지연 구조를 사용합니다.
leakage-free
누출 없는 (모델이 정답을 미리 학습하지 못하도록 설계된 상태)
“Asking about future matches makes the benchmark leakage-free by construction.”
미래 경기에 대해 묻는 것은 벤치마크를 구조적으로 누출 없게 만듭니다.
grounding
그라운딩 (모델의 출력을 실제 입력이나 증거에 근거하게 만드는 것)
“Video agents need dense spatiotemporal grounding to answer correctly.”
비디오 에이전트는 올바르게 답하기 위해 촘촘한 시공간적 그라운딩이 필요합니다.
temporal drift
시간적 표류 (긴 생성에서 오류가 누적되어 점점 벗어나는 현상)
“Their distillation method mitigates accumulated temporal drift in long videos.”
그들의 증류 기법은 긴 영상에서 누적된 시간적 표류를 완화합니다.
trade-off
절충, 상충 관계 (하나를 얻으면 다른 하나를 잃는 관계)
“There is a trade-off between compression and quality when choosing bit widths.”
비트 폭을 선택할 때 압축과 품질 사이에는 절충 관계가 있습니다.
