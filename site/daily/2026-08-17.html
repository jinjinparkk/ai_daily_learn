오늘의 기초 · Fundamentals

과적합과 정규화 Overfitting & Regularization
이게 뭐야? · What is it
ENOverfitting happens when a model learns the training data too closely, including its noise, and then fails on new data.
KO과적합은 모델이 학습 데이터를 노이즈까지 지나치게 세밀하게 학습해서 새로운 데이터에서는 제대로 작동하지 못하는 현상입니다.
ENRegularization is a set of techniques that discourage a model from becoming too complex, helping it generalize.
KO정규화는 모델이 지나치게 복잡해지지 않도록 억제하여 일반화 성능을 높이는 여러 기법을 말합니다.
ENThe goal is a model that performs well not just on data it has seen, but on data it has never seen.
KO목표는 이미 본 데이터뿐 아니라 한 번도 보지 못한 데이터에서도 잘 작동하는 모델을 만드는 것입니다.
작동 원리 · How it works
ENDuring training, a model adjusts its parameters to reduce the error on the training set.
KO학습 과정에서 모델은 학습 데이터셋의 오차를 줄이기 위해 파라미터를 조정합니다.
ENIf it has too much capacity and too little data, it can 'memorize' individual examples instead of finding general patterns.
KO모델의 용량이 너무 크고 데이터가 너무 적으면, 일반적인 패턴을 찾기보다 개별 예시를 '암기'해 버릴 수 있습니다.
ENWe detect this by comparing training error and validation error: a large gap signals overfitting.
KO이는 학습 오차와 검증 오차를 비교해 감지합니다. 두 값의 차이가 크면 과적합의 신호입니다.
ENL1 and L2 regularization add a penalty on the size of the weights, pushing the model toward simpler solutions.
KOL1과 L2 정규화는 가중치의 크기에 페널티를 더해 모델이 더 단순한 해로 향하도록 유도합니다.
ENDropout randomly turns off some neurons during training so the network cannot rely on any single path.
KO드롭아웃은 학습 중 일부 뉴런을 무작위로 꺼서 네트워크가 특정 경로 하나에만 의존하지 못하게 합니다.
ENEarly stopping halts training once validation performance stops improving, before the model starts memorizing.
KO조기 종료는 검증 성능이 더 이상 개선되지 않는 시점에 학습을 멈춰, 모델이 암기를 시작하기 전에 마무리합니다.
🧩 비유로 이해 · Analogy
ENIt is like a student who memorizes the exact answers to last year's exam: they ace the practice test but fail the real one with new questions.
KO이는 작년 시험의 정답만 통째로 외운 학생과 같습니다. 연습 시험은 만점을 받지만, 새로운 문제가 나오는 실제 시험에서는 무너집니다.
기본 용어 · Key terms
Generalization일반화. 학습하지 않은 새로운 데이터에서도 모델이 잘 작동하는 능력.
Validation set검증 세트. 학습 중 모델 성능을 점검하기 위해 따로 떼어 둔 데이터.
L2 regularizationL2 정규화. 가중치 제곱의 합에 페널티를 부과해 큰 가중치를 억제하는 기법.
Dropout드롭아웃. 학습 중 뉴런 일부를 무작위로 비활성화해 과적합을 줄이는 기법.
Early stopping조기 종료. 검증 성능이 나빠지기 시작할 때 학습을 멈추는 방법.

KO월드 모델은 어떤 환경과 그것이 시간에 따라 어떻게 변하는지를 내부적으로 표현하도록 학습하는 AI 시스템입니다.
ENInstead of reacting to each frame in isolation, it maintains a 'state' that carries memory forward.
KO각 장면을 개별적으로 반응하는 대신, 기억을 이어가는 '상태(state)'를 유지합니다.

KO덕분에 시스템은 미래 결과를 예측하거나 행동을 계획하거나 길고 일관된 시퀀스를 생성할 수 있습니다.

KO핵심 과제는 시퀀스가 길어질수록 메모리와 연산 비용이 무한정 커지지 않도록 제한하는 것입니다.
ENRecent work stores persistent state externally and retrieves only the relevant parts when needed.

핵심 영어 표현 · Vocabulary

overfitting
과적합. 모델이 학습 데이터에 지나치게 맞춰져 새 데이터에서 성능이 떨어지는 현상.
“We added dropout to reduce overfitting on the small dataset.”
작은 데이터셋에서의 과적합을 줄이기 위해 드롭아웃을 추가했습니다.
generalize
일반화하다. 학습하지 않은 데이터에도 잘 작동하다.
“A good model should generalize to inputs it has never seen.”
좋은 모델은 한 번도 본 적 없는 입력에도 잘 일반화되어야 합니다.
sample complexity
샘플 복잡도. 목표 성능을 달성하는 데 필요한 학습 예시의 수.
“The new method achieves linear sample complexity in the VC dimension.”
새 방법은 VC 차원에 선형인 샘플 복잡도를 달성합니다.
latent state
