오늘의 기초 · Fundamentals

배치와 에폭 Batch & Epoch
이게 뭐야? · What is it
ENA batch is a small group of training examples that a model processes together at one time.
KO배치는 모델이 한 번에 함께 처리하는 학습 예시들의 작은 묶음입니다.
ENAn epoch is one full pass through the entire training dataset.
KO에폭은 전체 학습 데이터셋을 한 번 전부 훑는 것을 말합니다.
ENThese two ideas describe how much data a model sees at each step and how many times it sees all the data.
KO이 두 개념은 모델이 각 단계에서 얼마나 많은 데이터를 보는지, 그리고 전체 데이터를 몇 번 보는지를 설명합니다.
작동 원리 · How it works
ENTraining data is usually too large to feed into a model all at once, so we split it into batches.
KO학습 데이터는 보통 너무 커서 한 번에 모델에 넣을 수 없기 때문에, 배치로 나눕니다.
ENFor each batch, the model makes predictions, measures its error, and updates its weights a little.
KO각 배치마다 모델은 예측을 하고, 오차를 측정한 뒤, 가중치를 조금씩 갱신합니다.
ENAfter all batches have been used once, the model has completed one epoch.
KO모든 배치를 한 번씩 사용하고 나면 모델은 한 에폭을 완료한 것입니다.
ENTraining usually repeats for many epochs so the model can gradually improve.
KO학습은 보통 여러 에폭 동안 반복되어 모델이 점진적으로 좋아지도록 합니다.
ENA small batch size gives noisier but more frequent updates, while a large batch size gives smoother but less frequent updates.
KO배치 크기가 작으면 갱신이 더 잦지만 노이즈가 많고, 배치 크기가 크면 갱신이 덜 잦지만 더 부드럽습니다.
ENChoosing the right batch size and number of epochs is a key part of tuning a model.
KO적절한 배치 크기와 에폭 수를 고르는 것은 모델을 조율하는 핵심 작업입니다.
🧩 비유로 이해 · Analogy
ENThink of studying a thick textbook: a batch is a few pages you review at a time, and an epoch is finishing the whole book once before starting over.
KO두꺼운 교과서를 공부한다고 생각해 보세요. 배치는 한 번에 복습하는 몇 페이지이고, 에폭은 책 전체를 한 번 다 끝낸 뒤 다시 시작하는 것입니다.
기본 용어 · Key terms
Batch size한 번의 갱신에 함께 사용되는 학습 예시의 개수.
Epoch전체 학습 데이터를 한 번 완전히 통과하는 것.
Iteration배치 하나를 처리하며 가중치를 한 번 갱신하는 단계.
Weight update오차를 줄이기 위해 모델의 파라미터를 조금 조정하는 것.

오늘의 핵심 개념 · Key Concept

장기 과제 Long-Horizon Task
ENA long-horizon task is one that requires many steps in sequence to finish.
KO장기 과제란 완료하기까지 여러 단계를 순서대로 거쳐야 하는 과제입니다.
ENIn robotics, this could mean picking up a tool, moving it, using it, and putting it back.
KO로봇공학에서는 도구를 집고, 옮기고, 사용하고, 다시 제자리에 두는 것을 뜻할 수 있습니다.
ENThe main difficulty is that small errors early on can build up and cause failure later.
KO가장 큰 어려움은 초반의 작은 오차가 쌓여서 나중에 실패로 이어질 수 있다는 점입니다.
ENAlso, one subtask can finish in a state that the next subtask cannot use.
KO또한 한 하위 작업이 다음 작업이 사용할 수 없는 상태로 끝나 버릴 수도 있습니다.
ENThe BATON paper tackles this by exploring each subtask separately and remembering its solution.
KOBATON 논문은 각 하위 작업을 따로 탐색하고 그 해법을 기억하는 방식으로 이 문제를 다룹니다.
왜 지금? · Why now
ENAs robots and agents take on multi-step real-world jobs, handling long-horizon tasks reliably is becoming a central challenge.
KO로봇과 에이전트가 여러 단계로 이루어진 실제 작업을 맡게 되면서, 장기 과제를 안정적으로 처리하는 것이 핵심 과제가 되고 있습니다.

Q. 모델 학습에서 에폭이란 무엇인가요?
What is an epoch in model training?
✅ 에폭은 모델이 모든 학습 데이터를 정확히 한 번 다 보았을 때 완료됩니다.
An epoch is completed when the model has seen all the training data exactly once.
Q. BATON 논문은 왜 각 하위 작업을 따로 탐색하나요?
Why does the BATON paper explore each subtask separately?
✅ 전체 작업 탐색 비용은 단계마다 곱셈적으로 늘어나므로, 하위 작업을 따로 탐색하면 더 저렴하고 어느 단계가 실패하는지 알 수 있습니다.
Whole-task exploration cost multiplies across stages, so exploring subtasks separately is cheaper and reveals which stage fails.
Q. 픽셀 공간 확산 논문이 보고한 핵심 발견은 무엇인가요?
What key finding did the pixel-space diffusion paper report?
✅ 먼저 잠재 공간에서 사전 지식을 학습한 뒤 픽셀 공간으로 옮겨, 품질을 유지하면서 3~4.75배 속도 향상을 얻었습니다.
They learn priors in latent space first, then move to pixel space, matching quality while gaining a 3–4.75x speedup.
