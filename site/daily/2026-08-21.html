오늘의 기초 · Fundamentals

단어 임베딩 Word Embeddings
이게 뭐야? · What is it
ENA word embedding is a way to represent a word as a list of numbers, called a vector.
KO단어 임베딩은 단어를 벡터라고 부르는 숫자 목록으로 표현하는 방법입니다.
ENThese numbers capture the meaning of a word so that computers can process language mathematically.
KO이 숫자들은 단어의 의미를 담아, 컴퓨터가 언어를 수학적으로 처리할 수 있게 해줍니다.
ENWords with similar meanings end up close to each other in this numerical space.
KO비슷한 의미를 가진 단어들은 이 숫자 공간에서 서로 가까이 위치하게 됩니다.
작동 원리 · How it works
ENComputers cannot understand raw text, so each word must first be turned into numbers.
KO컴퓨터는 원본 텍스트를 이해하지 못하므로, 각 단어를 먼저 숫자로 바꿔야 합니다.
ENA naive method gives each word a unique ID, but that tells us nothing about meaning.
KO단순한 방법은 각 단어에 고유 번호를 붙이는 것이지만, 이는 의미에 대해 아무것도 알려주지 않습니다.
ENEmbeddings instead learn vectors by looking at which words tend to appear near each other in huge amounts of text.
KO임베딩은 대신 방대한 텍스트에서 어떤 단어들이 서로 가까이 등장하는지를 관찰하여 벡터를 학습합니다.
ENThe core idea is that a word is defined by the company it keeps, known as the distributional hypothesis.
KO핵심 아이디어는 단어가 함께 등장하는 이웃 단어들로 정의된다는 것이며, 이를 분포 가설이라고 부릅니다.
ENDuring training, the model adjusts each vector so it can predict a word's context correctly.
KO학습 과정에서 모델은 단어의 문맥을 정확히 예측할 수 있도록 각 벡터를 조정합니다.
ENOnce trained, we can measure similarity between words by computing the distance or angle between their vectors.
KO학습이 끝나면 벡터 사이의 거리나 각도를 계산해 단어들 간의 유사도를 측정할 수 있습니다.
🧩 비유로 이해 · Analogy
ENThink of a map where every city is a point; cities close together share climate and culture, just as nearby word vectors share meaning.
KO모든 도시가 하나의 점인 지도를 상상해 보세요. 가까이 있는 도시는 기후와 문화를 공유하듯, 가까이 있는 단어 벡터는 의미를 공유합니다.
기본 용어 · Key terms
Vector (벡터)숫자들을 나열한 목록으로, 단어의 의미를 표현하는 데 사용됩니다.
Distributional Hypothesis (분포 가설)비슷한 문맥에서 나타나는 단어는 비슷한 의미를 가진다는 언어학 이론입니다.
Cosine Similarity (코사인 유사도)두 벡터 사이의 각도로 유사도를 측정하는 방법입니다.
One-hot Encoding (원-핫 인코딩)단어마다 한 자리만 1이고 나머지는 0인 벡터로, 의미 정보를 담지 못하는 단순 표현입니다.
Embedding Space (임베딩 공간)단어 벡터들이 놓이는 다차원 공간으로, 의미적 관계가 위치로 나타납니다.

오늘의 핵심 개념 · Key Concept

셀프플레이 강화학습 Self-Play Reinforcement Learning
ENSelf-play is a training setup where a model improves by competing or interacting with versions of itself.
KO셀프플레이는 모델이 자기 자신의 버전과 경쟁하거나 상호작용하며 발전하는 학습 방식입니다.
ENIn SPADE, a single language model plays two roles: one designs training environments and the other learns to solve them.
KOSPADE에서는 하나의 언어 모델이 두 역할을 맡습니다. 하나는 학습 환경을 설계하고, 다른 하나는 그것을 푸는 법을 배웁니다.
ENThe designer aims to create tasks that sit at the edge of the agent's ability, hard but still solvable.
KO설계자는 에이전트 능력의 경계에 놓인, 어렵지만 여전히 풀 수 있는 과제를 만들려고 합니다.
ENThis keeps the challenge fresh as the learner grows stronger, avoiding a fixed and stale set of problems.
KO이렇게 하면 학습자가 강해질수록 도전 과제가 계속 새로워져, 고정되고 진부한 문제 모음을 피할 수 있습니다.
ENThe approach uses the gap between performance with and without hints to estimate how challenging a task really is.
KO이 방식은 힌트가 있을 때와 없을 때의 성능 차이를 이용해 과제가 실제로 얼마나 어려운지 추정합니다.
왜 지금? · Why now
ENAs high-quality human data runs short, letting models generate their own diverse challenges is becoming a key path to further progress.
KO양질의 사람 데이터가 부족해지면서, 모델이 스스로 다양한 도전 과제를 만들어내는 것이 추가 발전의 핵심 경로로 떠오르고 있습니다.

What is the main idea behind word embeddings?

embedding

“The model converts each word into an embedding before processing.”

self-play
셀프플레이 (모델이 자기 자신과 상호작용하며 학습하는 방식)
“The agent improved through self-play without extra human data.”

inference
추론 (학습된 모델로 결과를 생성하는 과정)
“They split the model across machines to speed up inference.”
그들은 추론 속도를 높이기 위해 여러 컴퓨터에 모델을 분산했습니다.
precision

“High precision means the model gives the same answer every time.”

counterfactual
반사실 (특정 조건이 달랐다면 어떻게 되었을지를 따지는 것)
“They ran a counterfactual to measure one example's true effect.”

“Multi-vector models can improve retrieval quality.”
멀티 벡터 모델은 검색 품질을 향상시킬 수 있습니다.
interpretability
해석 가능성 (모델의 판단 근거를 사람이 이해할 수 있는 정도)
“Relevance propagation adds interpretability to the forecast.”
관련성 전파 기법은 예측에 해석 가능성을 더합니다.
