오늘의 기초 · Fundamentals

어텐션 메커니즘 Attention Mechanism
이게 뭐야? · What is it
ENThe attention mechanism lets a model decide which parts of the input matter most for the task at hand.
KO어텐션 메커니즘은 모델이 주어진 과제에서 입력의 어느 부분이 가장 중요한지 스스로 판단하게 해 줍니다.
ENInstead of treating every word or pixel equally, it assigns different weights to different pieces of information.
KO모든 단어나 픽셀을 똑같이 다루는 대신, 서로 다른 정보 조각에 서로 다른 가중치를 부여합니다.
ENIt is the core building block of the Transformer, the architecture behind most large language models today.
KO이것은 오늘날 대부분의 대형 언어 모델을 떠받치는 트랜스포머 아키텍처의 핵심 구성 요소입니다.
작동 원리 · How it works
ENEach input element is turned into three vectors: a query, a key, and a value.
KO각 입력 요소는 쿼리(query), 키(key), 값(value)이라는 세 개의 벡터로 변환됩니다.
ENThe query of one element is compared with the keys of all other elements to measure relevance.
KO한 요소의 쿼리를 다른 모든 요소의 키와 비교하여 관련성을 측정합니다.
ENThese comparison scores are normalized with a softmax so they add up to one, forming attention weights.
KO이 비교 점수들은 소프트맥스로 정규화되어 합이 1이 되고, 이것이 어텐션 가중치가 됩니다.
ENThe output is a weighted sum of the value vectors, emphasizing the most relevant information.
KO출력은 값 벡터들의 가중합으로, 가장 관련성 높은 정보를 강조하게 됩니다.
ENSelf-attention applies this process within a single sequence so each token can look at every other token.
KO셀프 어텐션은 이 과정을 하나의 시퀀스 안에서 적용해, 각 토큰이 다른 모든 토큰을 참조할 수 있게 합니다.
ENBecause every pair of tokens is compared, the cost grows with the square of the sequence length, which is why efficiency research matters.
KO모든 토큰 쌍을 비교하기 때문에 비용이 시퀀스 길이의 제곱에 비례해 커지며, 그래서 효율성 연구가 중요합니다.
🧩 비유로 이해 · Analogy
ENAttention is like reading a long document with a highlighter: you skim everything but color only the sentences that answer your specific question.
KO어텐션은 형광펜을 들고 긴 문서를 읽는 것과 같습니다. 전체를 훑어보되, 내 질문에 답이 되는 문장에만 색을 칠하는 것이죠.
기본 용어 · Key terms
Query / Key / Value어텐션에서 쓰이는 세 벡터로, 쿼리는 찾는 대상, 키는 비교 대상, 값은 실제 전달되는 정보를 나타냅니다.
Softmax여러 점수를 합이 1인 확률 분포로 바꿔 주는 함수로, 어텐션 가중치를 만드는 데 쓰입니다.
Self-attention하나의 시퀀스 안에서 각 요소가 다른 모든 요소를 참조하도록 하는 어텐션 방식입니다.
Transformer어텐션을 핵심으로 하는 신경망 구조로, 오늘날 대부분의 언어·이미지 생성 모델의 기반입니다.
Attention context모델이 한 번에 참조할 수 있는 정보의 범위로, 이 한계를 다루는 것이 효율성 연구의 초점입니다.

오늘의 핵심 개념 · Key Concept

제한된 어텐션 컨텍스트 Bounded Attention Context
ENAttention lets a model relate every element to every other element, but only within a fixed budget of context.
KO어텐션은 모든 요소를 서로 연결할 수 있지만, 정해진 컨텍스트 예산 안에서만 가능합니다.
ENWhen the number of items exceeds that budget, the model must split them into separate groups.
KO항목 수가 그 예산을 넘으면 모델은 이들을 별도의 그룹으로 나눠야 합니다.
ENSplitting breaks the direct connection between groups, so information can no longer flow freely between them.
KO그룹을 나누면 그룹 간 직접 연결이 끊겨 정보가 자유롭게 오갈 수 없게 됩니다.
ENThis causes inconsistency, such as an object that looks different across separately generated views.
KO이로 인해 따로 생성된 여러 시점 사이에서 물체가 다르게 보이는 등의 불일치가 생깁니다.
ENResearchers tackle this by compressing shared context or by rotating which items appear together during processing.
KO연구자들은 공유 컨텍스트를 압축하거나, 처리 도중 함께 등장하는 항목을 번갈아 바꾸는 방식으로 이 문제를 해결합니다.
왜 지금? · Why now
ENAs models generate more views, longer documents, or more characters at once, managing limited attention context has become a central engineering challenge.
KO모델이 한 번에 더 많은 시점, 더 긴 문서, 더 많은 인물을 생성하게 되면서, 제한된 어텐션 컨텍스트를 다루는 일이 핵심 엔지니어링 과제가 되었습니다.

In the attention mechanism, what are the three vectors created for each input element?
✅ 각 요소는 쿼리, 키, 값으로 변환되며, 이들이 함께 어텐션 가중치와 출력을 계산합니다.
Each element is turned into a query, a key, and a value, which together compute attention weights and outputs.
Q. 셀프 어텐션의 비용이 시퀀스 길이의 제곱에 비례해 커지는 이유는 무엇인가요?
Why does self-attention cost grow with the square of the sequence length?
✅ 셀프 어텐션은 모든 토큰을 다른 모든 토큰과 비교하므로 비교 횟수가 제곱으로 늘어납니다.
Self-attention compares every token with every other token, so the number of comparisons scales quadratically.
Q. 4DAnyone이 한 번에 여러 시점을 생성할 때 지적한 문제는 무엇인가요?
What problem does 4DAnyone identify when generating many target views at once?
✅ 타깃 시점이 한 번의 순전파를 넘으면 나눠야 하고, 이때 일관성을 깨뜨리는 제한된 어텐션 컨텍스트 문제가 드러납니다.
When target views exceed one forward pass, they must be split, exposing a bounded-attention-context problem that breaks consistency.
