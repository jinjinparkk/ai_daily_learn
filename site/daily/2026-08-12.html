오늘의 기초 · Fundamentals

신경망 Neural Network
이게 뭐야? · What is it
ENA neural network is a computing system loosely inspired by how neurons in the brain connect and pass signals.
KO신경망은 뇌의 뉴런들이 연결되어 신호를 주고받는 방식에서 느슨하게 영감을 받은 컴퓨팅 시스템입니다.
ENIt is made of layers of simple units that transform numbers into other numbers to recognize patterns.
KO신경망은 숫자를 다른 숫자로 변환해 패턴을 인식하는, 단순한 단위들의 여러 층으로 이루어져 있습니다.
ENAlmost all modern AI, including image recognition and chatbots, is built on neural networks.
KO이미지 인식과 챗봇을 포함한 거의 모든 현대 AI는 신경망을 기반으로 만들어집니다.
작동 원리 · How it works
ENEach unit, called a neuron, receives several input numbers and multiplies them by adjustable weights.
KO뉴런이라 불리는 각 단위는 여러 개의 입력 숫자를 받아 조정 가능한 가중치와 곱합니다.
ENIt then adds the results together, adds a bias, and passes the sum through an activation function that decides how strongly it fires.
KO그런 다음 결과를 모두 더하고 편향을 더한 뒤, 그 합을 활성화 함수에 통과시켜 얼마나 강하게 반응할지 결정합니다.
ENNeurons are organized into layers, and the output of one layer becomes the input of the next.
KO뉴런들은 여러 층으로 조직되며, 한 층의 출력이 다음 층의 입력이 됩니다.
ENDuring training, the network makes a prediction and compares it to the correct answer to measure its error.
KO학습 중에 신경망은 예측을 내놓고 그것을 정답과 비교하여 오차를 측정합니다.
ENAn algorithm called backpropagation sends this error backward through the layers to nudge each weight in a better direction.
KO역전파라는 알고리즘이 이 오차를 여러 층을 거쳐 거꾸로 보내, 각 가중치를 더 나은 방향으로 조금씩 조정합니다.
ENRepeating this process over many examples gradually turns a random network into an accurate one.
KO이 과정을 수많은 예제에 걸쳐 반복하면 무작위였던 신경망이 점차 정확한 신경망으로 변합니다.
🧩 비유로 이해 · Analogy
ENThink of a neural network like a team of taste-testers passing a soup down a line: each person tweaks the recipe a little, and feedback from the final taste tells everyone how to adjust next time.
KO신경망을 한 줄로 늘어서서 수프를 넘겨주는 시식단 팀이라고 생각해 보세요. 각 사람이 레시피를 조금씩 손보고, 마지막 시식의 피드백이 다음번에 어떻게 조정할지를 모두에게 알려줍니다.
기본 용어 · Key terms
Weight (가중치)입력 신호가 얼마나 중요한지를 나타내는 조정 가능한 숫자로, 학습을 통해 바뀝니다.
Activation Function (활성화 함수)뉴런의 입력 합을 받아 출력 강도를 결정하는 함수로, 신경망에 비선형성을 더합니다.
Backpropagation (역전파)예측 오차를 층을 따라 거꾸로 전파하여 가중치를 조정하는 핵심 학습 알고리즘입니다.
Layer (층)함께 작동하는 뉴런들의 묶음으로, 입력층·은닉층·출력층 등으로 구분됩니다.

오늘의 핵심 개념 · Key Concept

자기 증류 Self-Distillation
ENKnowledge distillation traditionally trains a smaller 'student' model to imitate a larger 'teacher' model.
KO지식 증류는 전통적으로 작은 '학생' 모델이 큰 '교사' 모델을 모방하도록 학습시키는 방법입니다.
ENSelf-distillation removes the separate teacher and lets a model learn from richer signals it produces about itself.
KO자기 증류는 별도의 교사를 없애고, 모델이 스스로에 대해 만들어 내는 더 풍부한 신호로부터 배우게 합니다.
ENInstead of just a single reward score, the model uses dense, token-level feedback that carries far more information.
KO단순한 하나의 보상 점수 대신, 모델은 훨씬 많은 정보를 담은 촘촘한 토큰 단위 피드백을 사용합니다.
ENIn today's CVPD paper, the model finds visual 'blind spots' where zooming in changes its answer, revealing knowledge it holds but underuses.
KO오늘 소개하는 CVPD 논문에서는 모델이 확대했을 때 답이 바뀌는 시각적 '사각지대'를 찾아내어, 자신이 가지고 있으나 충분히 활용하지 못한 지식을 드러냅니다.
ENThese discovered regions are turned into contrastive supervision so the model can improve without any external tools or annotations.
KO이렇게 발견된 영역은 대조적 지도 신호로 바뀌어, 외부 도구나 주석 없이도 모델이 스스로 개선될 수 있게 합니다.
왜 지금? · Why now
ENAs models grow larger, relying on stronger teachers becomes expensive, so self-contained improvement is increasingly attractive.
KO모델이 커질수록 더 강한 교사에 의존하는 것이 비싸지기 때문에, 스스로 완결되는 개선 방식이 점점 더 매력적으로 떠오르고 있습니다.

In a neural network, what does backpropagation primarily do?

Backpropagation propagates the error backward through the layers so each weight can be nudged toward a better value.

What makes CVPD's approach to self-improvement notable?

CVPD is a fully self-contained framework that converts the model's own visual blind spots into dense token-level supervision.
Q. 통섭 논문에 따르면, 어려운 문제에서 한결같이 높은 확신도는 무엇을 의미할 수 있나요?
