오늘의 기초 · Fundamentals

경사하강법 Gradient Descent
이게 뭐야? · What is it
ENGradient descent is an optimization method that gradually adjusts a model's parameters to reduce its error.
KO경사하강법은 모델의 오차를 줄이기 위해 파라미터를 점진적으로 조정하는 최적화 방법입니다.
ENIt is the core algorithm that lets neural networks 'learn' from data.
KO이것은 신경망이 데이터로부터 '학습'하게 해주는 핵심 알고리즘입니다.
ENThe 'gradient' tells us which direction increases the error the most, so we move the opposite way.
KO'기울기'는 오차를 가장 크게 늘리는 방향을 알려주므로, 우리는 그 반대 방향으로 움직입니다.
작동 원리 · How it works
ENFirst, we define a loss function that measures how wrong the model's predictions are.
KO먼저 모델의 예측이 얼마나 틀렸는지 측정하는 손실 함수를 정의합니다.
ENThen we compute the gradient, which is the slope of the loss with respect to each parameter.
KO그다음 각 파라미터에 대한 손실의 기울기인 그래디언트를 계산합니다.
ENWe update each parameter by taking a small step in the direction that lowers the loss.
KO손실을 낮추는 방향으로 작은 걸음을 내디디며 각 파라미터를 갱신합니다.
ENThe size of that step is controlled by a number called the learning rate.
KO그 걸음의 크기는 학습률이라 불리는 값으로 조절됩니다.
ENWe repeat this process many times until the loss stops decreasing much.
KO손실이 더 이상 크게 줄지 않을 때까지 이 과정을 여러 번 반복합니다.
ENIn practice we often use only a small batch of data each step, which is called stochastic gradient descent.
KO실제로는 매 단계마다 작은 데이터 묶음만 사용하는 경우가 많은데, 이를 확률적 경사하강법이라 합니다.
🧩 비유로 이해 · Analogy
ENImagine hiking down a foggy mountain: you can't see the bottom, so you feel the slope under your feet and step downhill a little at a time.
KO안개 낀 산을 내려간다고 상상해 보세요. 바닥이 보이지 않으니 발밑의 경사를 느끼며 조금씩 내리막으로 걸음을 옮기는 것과 같습니다.
기본 용어 · Key terms
Loss function (손실 함수)모델의 예측이 정답과 얼마나 차이 나는지를 수치로 나타내는 함수.
Gradient (기울기/그래디언트)각 파라미터를 조금 바꿀 때 손실이 얼마나 변하는지를 나타내는 방향과 크기.
Learning rate (학습률)한 번의 갱신에서 파라미터를 얼마나 크게 움직일지 정하는 값.
Stochastic Gradient Descent (확률적 경사하강법)전체 데이터가 아닌 무작위로 뽑은 작은 배치로 그래디언트를 추정해 갱신하는 방식.

오늘의 핵심 개념 · Key Concept

테스트 타임 적응 Test-Time Adaptation
ENMost deployed models freeze their parameters, so they cannot adjust to new situations after release.
KO대부분의 배포된 모델은 파라미터를 고정하므로, 출시 후 새로운 상황에 맞춰 조정할 수 없습니다.
ENTest-time adaptation lets a model keep improving on unseen inputs during actual use.
KO테스트 타임 적응은 모델이 실제 사용 중 처음 보는 입력에 대해 계속 개선되도록 합니다.
ENOne approach builds a loop of exploration, evaluation, reflection, and internalization without human labels.
KO한 접근법은 사람의 라벨 없이 탐색, 평가, 반성, 내재화의 순환 고리를 구성합니다.
ENThe model tries an action, judges the result, reflects on failures, and writes that lesson back into its weights.
KO모델은 행동을 시도하고, 결과를 평가하며, 실패를 되짚고, 그 교훈을 자신의 가중치에 다시 기록합니다.
ENThis matters for GUI agents that must handle interfaces they never saw during training.
KO이것은 학습 중 본 적 없는 인터페이스를 다뤄야 하는 GUI 에이전트에게 중요합니다.
왜 지금? · Why now
ENAs agents move from demos into real workflows, the ability to self-improve after deployment becomes essential.
KO에이전트가 데모를 넘어 실제 업무로 이동함에 따라, 배포 후 스스로 개선하는 능력이 필수적이 되고 있습니다.

핵심 영어 표현 · Vocabulary

gradient
기울기, 그래디언트 (손실이 파라미터에 대해 변하는 방향과 크기)
“We compute the gradient to know how to update the weights.”
가중치를 어떻게 갱신할지 알기 위해 그래디언트를 계산합니다.
loss function
손실 함수 (예측과 정답의 차이를 수치화하는 함수)
“A lower loss usually means the model fits the data better.”
손실이 낮을수록 보통 모델이 데이터에 더 잘 맞는다는 뜻입니다.
data-efficient
데이터 효율적인 (적은 데이터로 좋은 성능을 내는)
“The method is data-efficient, matching larger datasets with far fewer samples.”
이 방법은 데이터 효율적이어서, 훨씬 적은 샘플로 큰 데이터셋에 맞먹습니다.
closed-loop control
폐루프 제어 (결과를 피드백으로 받아 행동을 조정하는 제어)
“The robot uses closed-loop control to correct its motion in real time.”
그 로봇은 폐루프 제어를 사용해 실시간으로 움직임을 교정합니다.
temporal grounding

시간적 그라운딩은 영상이 정확히 언제 조작되었는지 보여줍니다.
self-consistent
자기 일관적인 (여러 답이 서로 모순되지 않는)
“We check whether the model's probability answers are self-consistent.”
우리는 모델의 확률 답변들이 자기 일관적인지 확인합니다.
inference
추론 (학습된 모델로 예측을 생성하는 과정)
